# GemRishi Headless Frontend

Frontend-first rebuild of GemRishi using Next.js App Router. Shopify is intentionally disconnected for the design/build phase.

## Stack
- Next.js
- React + TypeScript
- Vercel deployment
- GitHub source control
- Local/mock catalog data for frontend work

## Commerce integration later
Shopify Storefront API and Shopify checkout will be connected only after the frontend is approved. No Shopify Admin API secrets belong in the browser.
